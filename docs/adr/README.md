# Registros de decisão de arquitetura (ADR)

Cada decisão relevante vira um arquivo numerado, no formato proposto por
Michael Nygard: **Contexto**, **Decisão** e **Consequências**.
Um ADR nunca é apagado; se a decisão mudar, um novo ADR o substitui e o antigo
recebe o status `Substituído por ADR-XXXX`.

| ADR | Título | Status |
|---|---|---|
| [0001](0001-microservices-monorepo.md) | Microsserviços em monorepo | Aceito |
| [0002](0002-database-per-service.md) | Um banco de dados por serviço | Aceito |
| [0003](0003-technical-shared-library.md) | Biblioteca compartilhada apenas técnica | Aceito |
| [0004](0004-problem-details.md) | Erros no formato Problem Details (RFC 9457) | Aceito |
